## Notes/blockers

- Mode names. `/api/solution_modes` returns exactly two modes: `General Purpose` (masterSlices GP,HPCGPALL,HPCGPRYO) and `HPC and AI - Systems` (masterSlices HPCGP,HPCRYO,HPCGPALL,HPCGPRYO; UI label 'AI & HPC – ThinkSystem Hardware'). Each carries a `systemFunctionList` that is the website's own per-mode capability switch. GP: Quote true, VLH/P2PReport/P2PByRack/QuoteReference/Preference/AutoConnection/AutoArrange/COGValidation/AboutConfiguration/PlacementValidation false. HPC: those true, Quote false. MCP parity should be driven by this list.
- GP vs HPC differences actually seen: HPC top menu has no Software Defined Infrastructure; the same product launches a different CTO code (SR630 V3: 7D73CTO1WW in GP, 7D73CTOHWW 'HPC for AI' in HPC) via GET /sids/query/<category>; configurator gains Network and VLH tabs (+GET /getTopologies); workspace gains Cabling, Auto Connect, COG Validation, Guided/Expert, Preference, VLH, 'About Configuration'; exports gain Quote Reference, P2P Report, P2P by Rack, VLH, lose Quote.
- Workspace interactions are not plain clicks: racks/switches are added by drag (GP) or double-click (HPC) from the left catalog; a server enters a rack through the Summary page 'Move to > A1 - Rack', and only after Auto Connect > 'Automated Rack PDU' is switched off (otherwise the banner 'You cannot move hardware to this rack as PDU preferences have not been set' appears). The Preference panel says 'You need to add at least one rack' until a rack exists.
- Exports are form POSTs, not XHR: POST /api/ctos/export_zip (form field `data`, JSON of the whole workspace) returns application/octet-stream and one zip per Save. Quote_SupplyInfo and Message History produced empty zips for a plain CTO; XML-only gave a 71 KB CFXML; `/ctos/export` (Save button) returns XML directly.
- Transient: GET /service/portal/categories returned HTTP 400 in 2 of ~35 page loads, other loads 200. POST /lmc_validation (More > Manufacture Validation) always returned HTTP 500 'Call LMC server error ... HTTP error code : 400'. GET /auto/save/restore/list always 500. No 429/499/WAF block occurred; traffic stayed one page, serial, >=1 s apart (about 70 runs of short scripts, each loading the home bootstrap once).
- Not exercised by design or lack of an entry point: saving/emailing/ordering, anything under sign-in, deal registration, and the Restart-modal / new-experience LFO pickers (empty); LFO launch works through Part Search Preconfigured (7DCEA04VNA) and the classic start-page tile. Pass 2 reached the PCI wizard (SID0000978 > 7DGDCTO1WW) and the storage wizard UI (SID0001064 > 7DJRCTO1WW); the memory wizard remains unreachable (productCode=false everywhere).
- Client-side-only actions (no XHR) are marked WORKS only because the UI state changed; they have no wire contract to match, so an MCP equivalent only needs equal resulting state.
